## Project Description

Enterprise Grid ERP is an advanced, full-stack business management platform architected to streamline corporate operations through a highly clean, executive slate interface. 
The system provides robust modules for real-time inventory tracking, corporate HR/employee management, automated sales analytics, and high-fidelity order processing—all powered by a secure REST API and a premium, scalable frontend architecture using React and Redux Toolkit.
